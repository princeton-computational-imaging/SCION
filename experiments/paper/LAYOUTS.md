# Paper table layouts

The contract each renderer emits. The byte-exact rendering of every table on
a synthetic fixture pool (generated by `tests/fixtures/paper/generate_pool.py`)
is committed under `tests/fixtures/paper/expected/` and checked by
`tests/test_paper_render.py`; this file says what the rows and columns mean. Jobs and row/column choices live in `targets.yaml`.

Rules shared by every table:

- Output is a bare `tabular` (no float, caption or label) preceded by `%` lines
  naming the target, the level, the `git_sha` and the aggregation rule.
- **Level.** Quality and size of a cell always come from the same level.
  The headline level is `--level` (default `quantized`). Headline tables
  (1, 1a–1d, 2, 6) add the same rows at `codec`. Tables name the `codec`
  level `\wparam{}` ("w/ param.", parameter compression) in row labels and
  column groups; other levels appear as `(raw)`, `quantized`, etc.
- **Cells.** A per-scene cell is mean ± sample std (ddof=1) over the seeds,
  printed `$m_{\pm s}$`. A dataset-average cell first averages the scenes
  within each seed, then takes mean ± std over the per-seed means. Baseline
  cells are quoted values from `evals/baselines/baselines.yaml`; `---` = not
  reported (or a non-required gap, warned on stderr).
- **Sizes.** "MB ($2^{20}$ bytes)" = `size_bytes / 2**20`.
- **Highlight** (Tables 1, 1a–1d, 2, 6, compactness, OOD per scene): per column `\best{}` /
  `\second{}` on the displayed mean, ties shared.
- **Preamble.** Define `\best`, `\second` and `\wparam` (e.g.
  `\newcommand{\wparam}{w/~param.\@}`) in the paper preamble.
- Formats: PSNR 2 dp, SSIM and LPIPS 3 dp, MB 2 dp (1 dp from 100 MB; 3 dp
  below 1 MB for SCION cells and everywhere in Table 6; quoted baselines keep
  their source's precision), bits/G 1 dp (recomputed as
  `size_bytes * 8 / n_gaussians` of the same level), counts as integers.

Suggested caption sentence: "Mean $\pm$ sample standard deviation over
\nSeeds{} seeds; dataset columns average the scenes within each seed first."
